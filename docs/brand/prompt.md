# Minto visual identity

Name: **Minto**. Tagline: **Make room for clarity.**

Built-in ImageGen was used to create the icon. The resulting square opaque PNG was
resized to Apple's 1024-pixel app-icon format and a 512-pixel in-app/launch mark.
The generated original is retained in the image-generation output folder.

Project assets:

- `ios/LedgerApp/Assets.xcassets/AppIcon.appiconset/MintoIcon.png`
- `ios/LedgerApp/Assets.xcassets/MintoMark.imageset/MintoMark.png`
- `ios/LedgerApp/LaunchScreen.storyboard`

Exact generation prompt:

> Create a finished premium iOS app icon for a personal spending app named Minto. Square 1024x1024 full-bleed opaque canvas, deep forest green background (#19312E), centered single sculptural folded mint ribbon forming a soft lowercase m silhouette with two rounded arches and a gently rising right tip, subtle ceramic/satin 3D depth, mint and pale pistachio highlights, restrained soft directional light, immaculate edges, bold recognizable silhouette at small size. Calm, confident, contemporary finance meets wellness. Symbol occupies center 65% with generous padding. No letters as typography, no wordmark, no text, no coins, no dollar sign, no chart axes, no mockup device, no border, no pre-rounded outer icon corners. One icon only.
