# Demo media

`minto-demo.mp4` is a real iPhone 16 Pro simulator capture, encoded as H.264 MP4 with fast-start playback. `minto-demo.gif` is its smaller animated preview for GitHub Markdown. Both are under 1 MB.

The capture uses the Debug simulator-only `--demo --demo-tour` launch arguments documented in the [iOS guide](../../ios/README.md). It contains only generated expenses and a fictional profile. It makes no provider or backend calls. Summary text is an illustrative response calculated locally, not a recorded Gemini response. A persistent export label identifies the synthetic/offline demonstration, including on modal screens.

Re-record after material UI changes. Keep the synthetic label, verify every screen, and never capture a signed-in personal account for public demo media.
